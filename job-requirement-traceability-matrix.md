## How to read this document

* Every path in backticks is relative to the repository root and was checked to exist when this file was written.
* **Executed?** reflects only what is recorded in `docs/core-service-validation.md` (whole backend run 2026-10-17, no Docker: core-service 179 tests, notification-service 46, gateway 14, dsa-lab 53, 0 failures; plus a 57-check smoke run),
  `docs/e2e-validation.md` (Playwright), `frontend/README.md`, `frontend-angular/README.md` and `perf/README.md` / `PERFORMANCE-AND-TROUBLESHOOTING-GUIDE.md`.
* Frontend results recorded 2026-10-17: React Vitest 86 tests in 10 files (all pass), Angular Karma 83 specs (all pass), Playwright React e2e 17 run / 17 passed (16 passed + 1 skipped without the fault-injected second stack; `docs/e2e-validation.md`), Angular real-backend smoke 25/25 steps. Rows below that still say "no recorded run" for Vitest/Playwright predate these runs and should be read as executed.
* Interview Q numbers: the two banks overlap in numbering. **P1-Qn** = `docs/interview/INTERVIEW-BANK-PART1.md` (Q1-Q140), **P2-Qn** = `docs/interview/INTERVIEW-BANK-PART2.md` (Q131-Q260). Q131-Q140 exist in both files with different questions, hence the prefix.
* PDF chapters follow the planned outline. PDF1 = `01-...Architecture-and-Workflow` (chapters 1-24), PDF2 = `02-...Technical-Deep-Dive-and-Interview-Guide` (parts A-N:
  A Java/CS, B Spring, C React/TS, D Browser perf, E REST/system design, F PostgreSQL/Hibernate, G MongoDB/Redis, H RabbitMQ/distributed, I Multi-tenant SaaS, J AI integration, K Security, L Testing/CI-CD, M Observability/ops, N Senior engineering/leadership).
  The PDFs are planned and not in the repository at the time of writing; the numbers below are the target outline.
* Status values: **IMPLEMENTED-AND-TESTED** (code exists and a recorded executed test covers it), **IMPLEMENTED-NOT-EXECUTED(needs Docker)** (code exists, only compile-checked or never run), **CONCEPTUAL ONLY** (design/discussion, no running code).
